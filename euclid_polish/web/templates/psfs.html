PSF clusters (local sky positions + angular diameter)

Each ePSF is built from one spatial cluster of stars (the PSF varies across the focal plane). Cluster centres are read from the ePSF FITS; membership and angular diameter are reconstructed by assigning each catalog star valid in all four bands to its nearest cluster centre. × = cluster centre, Ø = angular diameter (arcmin).
