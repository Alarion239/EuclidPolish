🎯 Poster cutout — random object (clean 4-band FITS)

Generate a single random object as a clean (PSF-free, noise-free) Euclid cutout in all four bands (VIS · Y · J · H) on the HR 0.05″/pix grid — the idealised ground-truth scene. Toggle the Mode to pick the object kind, then submit; a blank seed re-rolls a fresh random object each time. Runs as a FASRC job; galaxy and lens modes need the TNG SKIRT atlas downloaded. Writes poster_cutout.fits + poster_cutout.png to _poster/ — load the preview, then download the FITS.

  • Star — a point source drawn from the active empirical stellar prior.
  • Gravitational lens — SIE + external shear with TNG light stamps.
  • TNG50 galaxy — a real TNG50 SKIRT stamp (random galaxy + viewpoint).
  • Random field — the current clean scene plus dirty and SR products.
