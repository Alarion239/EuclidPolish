What is round-trip training?

Self-supervised loss using real Euclid LR cutouts — no HR ground truth required. The model M is asked to super-resolve a real Euclid stamp, the output is pushed back through the VIS PSF + 2× sum-rebin (the deterministic forward operator EuclidVISForwardOp), and the asinh-stretched recon is compared to the asinh-stretched original LR:

loss = | asinh(Conv(M(lr)) / k) − asinh(lr_VIS / k) |

Mixed into the WDSR training batch via --roundtrip-fraction. Synthetic + HST + round-trip records get blended per batch; the trainer's source tag routes each example to the right loss.

Inspect a round-trip cutout

Fetches one sky_NNNN.fits bundle from FASRC, scales each band to total electrons (× t_total_s, matching the round-trip TFRecords), and renders the 4-band LR input. With a local checkpoint it also runs the model and shows the round-trip residual. Needs an active FASRC connection.

Step 1 · Download Euclid sky cutouts

Sample N random positions inside a sky disk and pull 4-band Euclid cutouts (VIS + NIR Y/J/H) from the SAS. Each position is bundled into a single multi-HDU FITS at $DATA_DIR/euclid_sky/cutouts/sky_NNNN.fits. Position catalogue at $DATA_DIR/euclid_sky/sky_positions.csv. Idempotent — already-downloaded bundles are skipped on re-submit.

{% with step_id="euclid_sky_download" %}{% include "_step_card_mount.html" %}{% endwith %}

Step 2 · Stack & chop into round-trip TFRecords

Reads the bundled per-position cutouts from step 1, stacks the four band HDUs into 4-channel cubes, chops each cube into stamp_size² LR stamps, multiplies pixel values by per-band t_total_s to convert archive e⁻/s → total electrons (so the units match the synthetic + HST records), and writes dirty_train.tfrecord + dirty_validate.tfrecord.

{% with step_id="euclid_roundtrip_tfrecords" %}{% include "_step_card_mount.html" %}{% endwith %}

Step 3 · Train WDSR with round-trip mix

Submit the WDSR trainer. The same card lives on Training; set roundtrip_fraction > 0 (e.g. 0.10–0.30) to mix the LR-only stamps from step 2 into each batch. The trainer instantiates EuclidVISForwardOp(rebin_factor=2) and routes per-example loss off the source tag — supervised L1 for synthetic/HST examples, asinh-space round-trip recon loss for the real-Euclid ones. Progress (stage + step + ETA) streams to the FASRC tab.
