Each tile shows the colour render: dirty LR VIS beside the super-resolved SR (same on-sky size), in linear and asinh stretch. Real cutouts have no ground truth and the true Euclid PSF is position-dependent and unknown, so there's no forward-model residual — the one PSF-independent pixel check is flux Σ SR/LR, which should sit near 1 (the deconvolution shouldn't invent or destroy flux). The quantitative morphology signal comes from Zoobot: when a Zoobot run is present, morph Δ shows how far morphology moved, and — for synthetic targets with HR — whether SR moved it toward the truth.
