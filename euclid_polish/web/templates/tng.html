TNG API token

Saved to ~/.tng_api_key on FASRC (mode 600) — the same file the download job reads on the compute node. Requires an active FASRC connection. The token is sent over the SSH channel as file content, never as a command argument, never to the job database, and never stored on this machine. Get the token from tng-project.org → API Token.

Download TNG50 SKIRT atlas

Bulk-fetch the full IllustrisTNG TNG50-1 SKIRT atlas (~1153 galaxies) as dusty Euclid cutouts — VIS + NISP Y/J/H, 5 orientations each (20 FITS/galaxy) — into {{ tng_dir }} on netscratch. Runs as a CPU SLURM job with one download thread per allocated CPU. Each finished galaxy gets a .done marker, so a re-submit after a time-limit only fills the gaps. Set your API token above first.
