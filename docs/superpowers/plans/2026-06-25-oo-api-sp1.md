# OO API — SP1 (OO core) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a clean, documented, object-oriented face to the EuclidPolish pipeline — `Model`, enriched `Cutout` hierarchy methods, and `PSFSet.draw_random` — so the generate → forward-model → super-resolve chain reads as ~5 lines. Provenance threads automatically (every cutout-producing method defaults `store=None → default_store()`, guarded). No call-site behaviour changes: the procedural paths keep working until SP3–SP5 migrate them.

**Architecture:** Two kinds of object — Operators (`MultiBandSimulator`, `MultiBandForward`, `Model`), built once and reused; Cutouts, typed immutable data handles that flow through operators and carry a `ProvId` + lineage. `Model` is the sole importer of `training.inference.reconstruct` (Task 3 removes `reconstruct` from `cutout/base.py`). `save_png` (Task 8) imports `plot_reconstruction` from `training.inference` at `cutout/base.py`'s module top — this is acyclic and allowed; the ONLY forbidden import edge is `cutout → model` (enforced by a test). All imports live at module scope — never function-scoped or inside a `try/except` (the project's hard rule).

**Tech Stack:** Python 3.12, TensorFlow 2.18, pytest, astropy, numpy.

from euclid_polish.psf.core import PSF
from euclid_polish.psf.psf_set import PSFSet


def _make_psf(val: float = 1.0) -> PSF:
    data = np.full((5, 5), val / 25.0, dtype=np.float32)
    return PSF(data=data, pixel_scale=0.05)


def _make_set(n: int = 3) -> PSFSet:
    return PSFSet.from_psfs([_make_psf(float(i + 1)) for i in range(n)])


def test_draw_random_returns_psf():
    pset = _make_set()
    rng = np.random.default_rng(42)
    result = pset.draw_random(rng)
    assert isinstance(result, PSF)


def test_draw_random_single_member_is_deterministic():
    """A set with one PSF always returns that PSF regardless of rng."""
    pset = PSFSet.from_psfs([_make_psf(1.0)])

```python
"""The :class:`Model` operator — public face of a trained checkpoint.

Wraps :func:`~euclid_polish.training.inference.load_model_from_checkpoint`
and :func:`~euclid_polish.training.inference.reconstruct`; the only module
in the codebase that imports the inference engine. Cutout objects are
pure data after SP1 and never import this module.

Import layering:
    model  →  cutout  (LRCutout/SRCutout are parameter/return types)
    model  →  training.inference  (engine)
    cutout  →  (nothing in model)          ← enforced by test
"""

from __future__ import annotations

from typing import Callable, Optional

import numpy as np

from euclid_polish.config import Config
from euclid_polish.cutout.base import LRCutout, SRCutout
from euclid_polish.provenance.checkpoint import model_id_of_checkpoint
from euclid_polish.provenance.defaults import default_store
from euclid_polish.provenance.ids import ProvId
from euclid_polish.sky.types import MultiBandSkyImage
from euclid_polish.training.inference import (
    load_model_from_checkpoint as _default_load,
    reconstruct as _default_reconstruct,
)

_HR_SCALE = Config.DEFAULT_PIXEL_SCALE   # 0.05 arcsec/pix


class Model:
    """The public face of a trained WDSR checkpoint.

    Parameters
    ----------
    checkpoint_dir : str
        Path to the TF checkpoint directory.
    scale : int
        Super-resolution upscale factor (default 2).
    num_res_blocks : int
        Number of residual blocks (default ``Config.DEFAULT_NUM_RES_BLOCKS``).
    _load_fn : callable, optional
        Injection point for tests — replaces ``load_model_from_checkpoint``.
    _reconstruct_fn : callable, optional
        Injection point for tests — replaces ``reconstruct``.
    """

    def __init__(
        self,
        checkpoint_dir: str,
        *,
        scale: int = 2,
        num_res_blocks: int = Config.DEFAULT_NUM_RES_BLOCKS,
        _load_fn: Optional[Callable] = None,
        _reconstruct_fn: Optional[Callable] = None,
    ) -> None:
        load_fn = _load_fn if _load_fn is not None else _default_load
        self._tf_model = load_fn(
            checkpoint_dir,
            scale,
            num_res_blocks,
        )
        self._scale = int(scale)
        self._reconstruct_fn: Callable = (
            _reconstruct_fn if _reconstruct_fn is not None else _default_reconstruct
        )
        self.id: Optional[ProvId] = model_id_of_checkpoint(checkpoint_dir)

    # ------------------------------------------------------------------ #
    # Raw-array escape hatch
    # ------------------------------------------------------------------ #

    def upsample_array(self, arr: np.ndarray) -> np.ndarray:
        """Super-resolve a bare numpy array; return the SR array.

        Parameters
        ----------
        arr : np.ndarray
            LR image in raw electrons — 2D ``(H, W)`` or 3D ``(H, W, C)``.

        Returns
        -------
        np.ndarray
            SR output in raw electrons. Shape is ``(H·scale, W·scale)``
            for a single-output model or ``(H·scale, W·scale, C)`` for
            the 4-band VIS+NISP model.
        """
        _lr_display, sr_data = self._reconstruct_fn(self._tf_model, arr)
        return np.asarray(sr_data, dtype=np.float32)

    # ------------------------------------------------------------------ #
    # Typed-cutout verb
    # ------------------------------------------------------------------ #

    def upsample(
        self,
        lr: LRCutout,
        *,
        store=None,
    ) -> SRCutout:
        """Super-resolve an :class:`~euclid_polish.cutout.base.LRCutout`.

        The SR cutout's parents are ``(self.id, lr.id)`` (model.id is
        omitted when it is ``None``, i.e. a legacy checkpoint without a
        provenance sidecar). The new cutout's id is minted via ``store``
        (or ``default_store()`` when ``store`` is ``None``). The provenance
        operation is guarded: a store failure degrades to an unstamped but
        correct artifact.

        Parameters
        ----------
        lr : LRCutout
            The low-resolution input cutout.
        store : ProvStore, optional
            Provenance store. Defaults to ``default_store()``.

        Returns
        -------
        SRCutout
        """
        _lr_display, sr_data = self._reconstruct_fn(self._tf_model, lr.image.data)
        sr_data = np.asarray(sr_data, dtype=np.float32)

        # Band names: inherit multi-band shape, fall back to VIS-only.
        if sr_data.ndim == 3 and sr_data.shape[-1] == len(lr.band_names):
            bands = lr.band_names
        else:
            bands = ("VIS",)

        sr_img = MultiBandSkyImage(
            data=sr_data,
            pixel_scale_arcsec=_HR_SCALE,
            band_names=bands,
            is_clean=True,
            subset=lr.image.subset,
        )

        # Resolve store and mint id — guarded so provenance never blocks SR.
        parents = tuple(p for p in (self.id, lr.id) if p is not None)
        try:
            _store = store if store is not None else default_store()
            new_id = _store.mint()
        except Exception:   # noqa: BLE001 — provenance is best-effort
            new_id = ProvId.sentinel()   # ProvId is imported at module top

        return SRCutout(
            image=sr_img,
            id=new_id,
            parents=parents,
        )

    # ------------------------------------------------------------------ #
    # SP2 stubs (declared here; implemented in SP2)
    # ------------------------------------------------------------------ #

    def eval_catalog(self, *args, **kwargs):  # noqa: ANN001
        """Evaluate the model on a lens catalog. Implemented in SP2."""
        raise NotImplementedError("eval_catalog is implemented in SP2")

    def eval_grouped(self, *args, **kwargs):  # noqa: ANN001
        """Evaluate the model on grouped real-galaxy cutouts. Implemented in SP2."""
        raise NotImplementedError("eval_grouped is implemented in SP2")
```

        fetches each band from the Euclid archive (default) or from an

        ``MAGZERO`` → :func:`~euclid_polish.euclid.photometry.adu_per_s_to_electrons_factor`.
        Inject ``fetch_plane(ra, dec, band_name, size) -> np.ndarray``

        Parameters
        ----------
        ra, dec : float
            ICRS coordinates in degrees.
        size : int
            Cutout side in VIS pixels (0.10″/pix reference grid).
        bands : sequence of str
            Band names to fetch (default ``Config.LR_INPUT_BAND_NAMES``).

            band_names=tuple(bands),
            is_clean=False,

            new_id = _store.mint()

            new_id = ProvId.sentinel()   # ProvId is imported at module top

    @classmethod
    def _fetch_planes_from_archive(
        cls,
        ra: float,
        dec: float,
        size: int,
        bands: "Sequence[str]",
    ) -> "list[np.ndarray]":
        """Real Euclid archive download path: fetch + MAGZERO → e⁻.

        Not called in tests (fetch_plane injection bypasses this). Kept
        in a classmethod so it can be mocked independently if needed. All
        imports it uses (os, tempfile, _fits, fetch_cutout_at) are at the
        module top — never re-import inside this method.
        """
        planes = []
        for band_name in bands:
            band = Config.get_band(band_name)
            with tempfile.NamedTemporaryFile(suffix=".fits", delete=False) as tf:
                tmp_path = tf.name
            try:
                ok, err = fetch_cutout_at(
                    ra=ra, dec=dec, band_name=band_name,
                    output_file=tmp_path,
                    cutout_size_vis_pixels=size,
                )
                if not ok:
                    raise RuntimeError(
                        f"EuclidLRCutout.fetch: band {band_name} failed: {err}"
                    )
                with _fits.open(tmp_path) as hdul:
                    arr = hdul[0].data.astype(np.float32)
                    magzero = float(
                        hdul[0].header.get("MAGZERO", band.sim_zeropoint_e))
                factor = np.float32(adu_per_s_to_electrons_factor(magzero, band))
                planes.append((arr * factor).astype(np.float32))
            finally:
                try:
                    os.unlink(tmp_path)
                except OSError:
                    pass
        return planes
  ```

        """Write this cutout's data to a FITS file with provenance cards.

        The pixel data is written as float32. Multi-band data ``(H, W, C)``
        is stored as a 3D FITS image with ``C`` planes ordered along
        NAXIS3 (planes are channels in :attr:`band_names` order).

            SR, or the VIS FITS header for LR). A blank header is used
            when None.

               if wcs_header is not None else _fits.Header())

            if _bad in hdr:

        # Multi-band (H, W, C) → FITS convention (C, H, W) on NAXIS3.
        if arr.ndim == 3:

        if self.band_names:

        try:
            write_stamp_cards(hdr, self.prov_stamp())
        except Exception:   # noqa: BLE001 — provenance cards are best-effort
            pass
        hdu = _fits.PrimaryHDU(arr, header=hdr)
        hdu.writeto(path, overwrite=True, output_verify="silentfix")

    def save_png(
        self,
        path: str,
        *,
        regime: str = "eye",
        lr: "Optional[LRCutout]" = None,
        hr: "Optional[HRCutout]" = None,
    ) -> None:
        """Render a reconstruction figure and write it as a PNG.

        Wraps :func:`~euclid_polish.training.inference.plot_reconstruction`.

        Parameters
        ----------
        path : str
            Output PNG path.
        regime : str
            Colour regime: ``"eye"`` (physical blackbody-T colours, default)
            or ``"calibrated"`` (solar-balanced adaptive windows).
        lr : LRCutout, optional
            The dirty LR input — shown in the LR panel. When None, a blank
            LR panel is used.
        hr : HRCutout, optional
            The ground-truth HR target — shown in the HR panel and used for
            residual metrics. When None, the no-HR layout is used.
        """
        sr_data = np.asarray(self.data, dtype=np.float32)
        n_bands = len(self.band_names)

        # LR: extract VIS plane for the main LR panel; keep cube for colour.
        lr_data = lr_cube = None
        if lr is not None:
            lr_arr = np.asarray(lr.data, dtype=np.float32)
            if lr_arr.ndim == 3 and lr_arr.shape[-1] > 1:
                lr_cube = lr_arr
                lr_data = lr_arr[..., 0]
            else:
                lr_data = lr_arr[..., 0] if lr_arr.ndim == 3 else lr_arr
        if lr_data is None:
            # No LR supplied: use the SR's VIS channel rebinned down as proxy.
            vis = sr_data[..., 0] if sr_data.ndim == 3 else sr_data
            # Simple 2× average pool for display only.
            h, w = vis.shape[:2]
            lr_data = vis.reshape(h // 2, 2, w // 2, 2).mean(axis=(1, 3))

        # HR: extract VIS plane; keep cube for colour.
        hr_data = hr_cube = None
        if hr is not None:
            hr_arr = np.asarray(hr.data, dtype=np.float32)
            if hr_arr.ndim == 3 and hr_arr.shape[-1] > 1:
                hr_cube = hr_arr
                hr_data = hr_arr[..., 0]
            else:
                hr_data = hr_arr[..., 0] if hr_arr.ndim == 3 else hr_arr

        _plot_reconstruction(
            lr_data=lr_data,
            sr_data=sr_data,
            hr_data=hr_data,
            output_path=path,
            lr_cube=lr_cube,
            hr_cube=hr_cube,
            rgb_mode=regime,
        )
  ```

## Ambiguities resolved

1. **`downsample` vs `convolve` back-compat:** The spec says rename; no SP1 call-site migration. Added a `grep` step in Task 4 to catch any production callers of `.convolve(` that must be updated before the rename lands.

2. **`EuclidLRCutout.query` fate:** Kept as-is. It is the internal low-level seam (takes an already-in-electrons `fetch_plane`). `fetch` is the new high-level entry point that does the MAGZERO conversion; `query` remains for backward compatibility and internal testing of the stack step.

3. **`simulate_field` signature:** `MultiBandSimulator.simulate_field(rng, *, n_galaxies=None, ...)` returns `(MultiBandSkyImage, dict)`. The `generate` classmethod passes only `rng` (relying on the simulator's Poisson counts), which is the normal usage. Callers that want `n_galaxies` fixed call `simulator.simulate_field(rng, n_galaxies=N)` directly and construct `SyntheticHRCutout` themselves.

4. **`save_png` with no LR:** When `lr=None`, a proxy 2× rebinned SR VIS plane is used for the LR panel (rather than raising). This keeps the method always callable — the rendered figure will not have a true LR reference but will still be a valid PNG.

5. **`SRCutout.save_png` imports `training.inference`:** This re-introduces a cutout→training dependency, but only on `SRCutout` (a leaf subclass) and only for rendering. The critical constraint — `cutout.base` must not import `model.py` — is maintained. The import-cycle test in Task 2 checks for `"euclid_polish.model"` in `cutout.base`, not for `training.inference`.

6. **`store.mint()` failure guard:** Every guard catches `Exception` (broad) and falls back to `ProvId.sentinel()`. This is intentional: provenance must never block the operation, and a sentinel id is distinguishable from a real one.

7. **`Model._reconstruct_fn` injection:** Stored as an instance attribute set in `__init__` (and in `__new__`-based test setup). This keeps the injection point explicit and avoids monkeypatching module globals, which can bleed across tests.
