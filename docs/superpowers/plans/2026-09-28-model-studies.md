# Model Studies Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Freeze the whole ensemble's comparison data (plus up to 10 fields, stored on holylabs) into an immutable study that Figures › Studies browses interactively and exports as publication figures, independent of the live members.

**Architecture:** A backend package `euclid_polish/studies/` (store, candidates, numbers, fields, stats, render) with Flask routes `/api/studies*` and a `study` viewer collection; a frontend freeze dialog on Models › Leaderboard and a Figures › Studies tab. Spec: `docs/superpowers/specs/2026-09-28-model-studies-design.md`.

**Tech Stack:** Flask, NumPy, matplotlib (presentation style), SSH ControlMaster (`web/remote.py`), React + TS, vitest, pytest.

## Corrections to the spec found while mapping the code (binding)

- The knee grid is `KNEE_GRID_E` (21 knees, `euclid_polish/eval/knee_psnr.py:21`), not 11.
- `ensemble_knee_psnr.json` keeps only field means: per-field curves are computed at freeze time by the same loop as `compute_knee_psnr_payload`'s `field_curves` (`web/helpers/ensemble_viz.py:2446`), keeping the per-field arrays.
- Studies do NOT live inside a tracking campaign (none may be active, and `save_campaign` moves `current/`). They live in their own store: local `Config.TRACKING_DIR/studies/<id>/` (numbers + manifest) and remote `<remote tracking dir parent>/study_fields/<id>/` (fields). The remote field root must be outside any directory `tracking.sync.push` mirrors with delete semantics — verify the rsync flags and pick a path push can never delete. The numbers are mirrored by an explicit rsync of `studies/<id>/` after completion.
- Blackout cubes hold only `lr_` and `member{i}_`: at freeze, a blackout field's mean is computed from the member stack and its gate output by applying the production gate (`load_combiner`/`apply_field` with the members it reads); its hole mask comes from `spatial_gate_compare.hole_masks`. Members whose blackout cube is missing make the field unavailable.
- A compare report may be absent (`<regime>/spatial_gate_comparison.json`): `gate.json` then records the weight diagnostic only and says so.
- Plate style: `euclid_polish/visualization/presentation_style.py` (`presentation_rc`, `apply_presentation_figure`), pattern of `web/helpers/publication_figures.py:render_population_atlas`.
- Disk: reuse `experiments.free_bytes` / `MIN_FREE_BYTES` (5 GiB) / `DiskSpaceError`, and the `MemberCacheBudget` LRU pattern for the fetched-field cache (budget 2 GiB, never below the 5 GiB margin).

## Task 1 — Backend: store, candidates, freeze job, fields, stats, render, routes

**Files:** create `euclid_polish/studies/{__init__,store,candidates,numbers,fields,stats,render}.py`; `euclid_polish/web/routes/studies.py` (registered with the app like the other route modules); `euclid_polish/web/helpers/viewer_data.py` (a `study` collection in `_REGISTRY`); `euclid_polish/web/API.md`; tests `tests/test_studies_*.py` (tmp dirs and a fake SSH session only — never the real data dir or FASRC).

- [ ] `store.py`: `StudyStore(root)`; `create(name, note) -> id`; manifest read/write (atomic); `list()` (complete + incomplete with reason); `delete(id, ssh)` (local dir + remote field dir, guarded path check like `_delete_remote_member`); `set_note`, `selections` sidecar (`selections.json`, the only mutable files). Tests: roundtrip, immutability of `numbers/`, incomplete listing, guarded delete.
- [ ] `candidates.py`: `candidates(starless) -> {ensemble: {...status per numbers block with stale reasons...}, fields: [{kind: test|blackout|real, id, label, available, reason, bytes, thumb_url}]}`; a field is available only when every active member's SR exists (test: `member{i}_NNNNN.npy` for all i in the current test manifest whose `member_labels` equal the registry's; blackout: all members' blackout cubes; real: `CachedTileMembers(...).cached(label)` for all labels with the tile's current `lr_sha`). Read-only. Tests with a tmp cube dir.
- [ ] `numbers.py`: build `members.csv` (recipe from `origin.json` via `_member_origin`, status/steps from `_member_row` or `member_progress`, fingerprints), `knee_psnr.json` (per member/mean/gate × band × field on `KNEE_GRID_E`, plus `knees`, `bands`, `fields`), `integrated.csv`, `training_curves.json` (`training_curves_payload`), `gate.json` (diagnostic + latest compare report + variants summary), `real.json` (experiments whose `model_labels`/fingerprints match this membership). Tests: shapes, integrated = `integrated_psnr` of the per-field curves, missing compare report handled.
- [ ] `fields.py`: `pack_field(kind, id) -> iterator of (product_name, npz_path, meta)` writing ONE product at a time to a temp dir (np.savez_compressed float32; products: `member_<label>`, `mean`, `gate`, `lr`, `hr` (test only), `mask` (blackout), `truth.json`, `field.json`); `upload(ssh, local, remote)` via `write`/rsync of one file, then remote `sha256sum` must equal the local digest, then delete the temp file; `fetch(ssh, study, field, cache)` into the LRU cache with the disk margin. Tests with a fake SSH that records commands and simulates sha mismatch (must fail and keep the study incomplete).
- [ ] Freeze job (`routes/studies.py`): `POST /api/studies` (form: name, note, mode, fields ≤ 10) spawns one cancellable `REGISTRY.spawn(..., kind="study-freeze")` job: numbers → manifest (incomplete) → fields one by one (progress per product) → `complete` → rsync numbers to the remote mirror. `POST /api/studies/<id>/resume` continues an incomplete study. `GET /api/studies`, `GET /api/studies/<id>` (manifest + numbers), `GET /api/studies/candidates?mode=`, `POST /api/studies/<id>/note`, `POST /api/studies/<id>/selections`, `POST /api/studies/<id>/delete` (confirmed in UI), `POST /api/studies/<id>/fields/<fid>/fetch` (job), `GET /api/studies/<id>/figure/<chart>?format=png|pdf|svg&dpi=&selection=&...` and `.../figure/<chart>.csv`. Fields require FASRC (`requires_fasrc` on the handlers that touch SSH); numbers never do. Refuse > 10 fields and a margin violation with clear JSON errors.
- [ ] `stats.py`: `paired_bootstrap(a, b, *, n=2000, seed=0) -> {mean, lo, hi, n_fields}` over fields (paired resampling of field indices); group helpers (median + p16–p84 across members). Tests: known distributions, determinism by seed.
- [ ] `render.py`: backend figures in the plate style for the six charts in the spec (knee curves, integrated by loss×knee, paired Δ with CIs, gate weight by member/family, training curves, real metrics); each returns bytes and the CSV of exactly the plotted numbers. Tests: each renders png/pdf/svg from a tiny fixture study; CSV columns.
- [ ] Viewer collection `study`: meta/cube from the fetched-field cache (tiers: LR, HR, mean, gate, each member hidden-by-default like the ensemble collection), 404 with "fetch the field first" when not cached. Test.
- [ ] Run `$PY -m pytest -q tests/test_studies_*.py` and the full suite; ruff.
