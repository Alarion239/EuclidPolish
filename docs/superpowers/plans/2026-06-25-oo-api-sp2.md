# OO API — SP2 (eval on Model) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add `Model.eval_catalog(...)` and `Model.eval_grouped(...)` as thin, behaviour-preserving wrappers over the existing eval runners, reusing the model already loaded in the `Model` instance.

**Architecture:** The runners (`run_catalog_eval`, `run_grouped_analysis`) each load the TF model internally at one line. We add an optional `model=None` bypass: when supplied, skip the internal `load_eval_model`. `Model.eval_*` pass `self._tf_model`. No orchestration is rewritten — the manifest format, outputs, and existing call sites are unchanged.
