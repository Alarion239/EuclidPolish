### Step scaling and the learning-rate schedule
- **257's milestones** (0.2/0.5/1/2/4/8/15M): 59.18/60.60/61.11/61.54/61.94/62.48/62.82 dB. That is about 0.4–0.5 dB per doubling, still not flat within the run.
- **Fully annealed runs, same recipe at both ends:** about 0.3–0.4 dB per doubling up to 2M; about 0.22 dB per doubling from 2M to 15M.
- **The cosine length equals the run's own target step count** (`model.py:796-798`). So a milestone inside a long run is taken at high LR and is not equivalent to a shorter run: 257@200k is 1.21 dB below 255, which annealed fully at 200k.
- **258's continuation to 950k was broken** ✔. Continuing to a larger target re-heated the LR from 2e-5 to 4.5e-4 with no warmup. The reset spike guard then rolled back 10× and halved the LR 5×, so the last 750k steps ran at ≤1/32 of the LR. **"Smooth model trained longer" has therefore not really been tested.**
- **`continue` resumes from the best-validation checkpoint, not from final/.** 258's served model is its 380k checkpoint. 257's best was 1.67M steps behind its end, and 257 is unscored and unregistered as a universal model.

- **Flux is NOT paper-ready.** On synthetic fields, 238 conserves flux (0.999 / 0.973 / 0.953 at 19–23 / 24–25 / 25–26 mag), and a correct deconvolution should give SR/input > 1 there (truth/input is 1.07–1.10). On real sky 238 falls to 0.905 at 24.5–25 mag, a 10–15% faint deficit that the simulation does not show.
- **Still needed for the flux result:**
  - a like-for-like synthetic expectation, using MER-Kron apertures on the v6 test set;
  - no-blur controls at equal steps;
  - a model trained on v6;
  - error bars and caveats: blends excluded, nothing brighter than 20 mag, one field, NISP only in 4.9″ apertures.
- **The cause story.** v5 training noise was mean-stacked, so it is more correlated than real MER noise (lag-1 VIS .243 vs .205, NISP .86 vs .80). That correlation reproduces the outskirt loss. The noise-jitter run (228) fixes it, and v6 fixes it at the source. Galaxy blur reduces fake texture but does not restore flux.
- **What a v6 model should show if this is right:**
  - injection recovery ≥0.85;
  - faint Kron SR/input ≥0.98, not falling with training length;
  - MER pull ≈ 0σ;
  - lower dropouts and texture;
  - resolution never blurrier.
